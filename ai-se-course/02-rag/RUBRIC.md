# שלב 2 — קריטריונים לביקורת

צירים קבועים לכל תרגיל: **נכונות · עיצוב · מוכנות לייצור · קריאות** (1–5), כמו בשלב 1.

## 2.1 Chunking
- [ ] regex לכותרות מעוגן לתחילת שורה ודורש רווח.
- [ ] כל הכללים מתקיימים גם עם overlap גדול יחסית ל-max_chars.
- [ ] לא מאבד טקסט (חוץ מרווחים) ולא משכפל פסקאות שלמות מעבר לחפיפה.
- [ ] פונקציות עזר קטנות (פיצול פסקה, אריזה) במקום פונקציה אחת ארוכה.
- [ ] הבנה: יציבות מזהים בעדכון מסמך; טבלאות.

## 2.2 וקטורים
- [ ] וקטורי לחלוטין (בלי לולאת Python על שורות); `np.divide(..., where=...)` או מקבילה.
- [ ] טיפוסי Python בפלט (`int`, `float`), לא `np.int64`.
- [ ] tie-break מפורש ונכון (`lexsort`/`argsort(kind="stable")`).
- [ ] הבנה: נרמול מראש; `argpartition` לביצועים במאגר גדול.

## 2.3 BM25
- [ ] חישוב מוקדם ב-`__init__` (df, אורכים, avgdl, Counter לכל מסמך).
- [ ] `idf` לפי הנוסחה; מונחים כפולים בשאלה נספרים פעם אחת.
- [ ] בדיקת "עבריות" של מילה נכונה (טווח Unicode), לא רק "לא ASCII".
- [ ] הבנה: false positives של הסרת תחיליות; חלופות (מנתח מורפולוגי, n-grams).

## 2.4 היברידי
- [ ] RRF לא תלוי בסקאלת הציונים; tie-break לפי הופעה ראשונה.
- [ ] `hybrid_search` ממחזר את `top_k` מ-2.2 ולא משכפל קוד.
- [ ] הבנה: למה RRF ולא ממוצע ציונים; משקלים שונים לכל צד.

## 2.5 הערכה
- [ ] פונקציות טהורות ופשוטות; שגיאה על קלט ריק.
- [ ] **החלק הפתוח:** golden set מגוון (מזהים, מספרים, בלי-תשובה), טבלת השוואה, ומסקנות מנומקות.

## 2.6 Mini RAG
- [ ] אינדקס פעם אחת; לא בונה BM25/embeddings מחדש בכל שאלה (או לפחות מזהה את זה כבעיה ומסביר).
- [ ] **סינון הרשאות לפני הדירוג.**
- [ ] אין קריאה למודל כשאין תוצאות/ציון נמוך.
- [ ] אימות ציטוטים, בלי כפילויות, שמירת סדר.
- [ ] הנחיית מערכת: עיגון, פורמט ציטוט, משפט "לא מצאתי" מדויק, נתונים ≠ הוראות.
- [ ] `stop_reason` נבדק; טקסט נאסף מכל בלוקי ה-text.
- [ ] הבנה: כיול הסף; קנה מידה.
