# Codyssey – Personalized Coding Learning Platform 🚀


**Codyssey** is a modern web platform that helps users learn programming by following curated and AI-generated learning tracks. Whether you’re a beginner or an experienced coder, Codyssey provides structured challenges to sharpen your skills and build real-world projects.

---

## 🌟 Features

- **Personalized Learning Tracks** – Choose a language, category, and difficulty level.  
- **AI-Powered Custom Tracks** – Pro users can generate their own coding tracks using OpenAI GPT API.  
- **Practice-Oriented** – Focused on real coding tasks, not just theory.  
- **Multi-Language Support** – Python, JavaScript, C++.  
- **Progress Tracking** – Save solutions, track completion, and view your coding journey.  
- **Dark Mode** – Switch seamlessly between light and dark themes.  
- **Pro Experience Sandbox** – Test the Pro features without paying.

## 🛠 Technologies

- **Frontend:** React, Tailwind CSS, React Router  
- **Backend:** Django REST Framework, dj-rest-auth, Django Allauth  
- **AI Integration:** OpenAI GPT API (for Pro users) & Mistral API (for free users)  
- **Deployment:** Render (full-stack deployment)  
- **Authentication:** Session-based login, Google OAuth

## 🎯 How It Works

1. Browse categories and select a programming language.  
2. View curated learning tracks with practical coding tasks.  
3. For Pro users, generate custom tracks by entering learning goals.  
4. Track progress, submit solutions, and revisit tasks anytime.

## 🚀 Deployment

The app is fully deployed on Render. No local setup is required to try it.  

If you want to run it locally:

```bash
# Clone the repo
git clone [https://github.com/yourusername/codyssey](https://github.com/1oRamos1/restAPI.git)

# Backend setup
cd mysite
python -m venv venv
source venv/bin/activate  # macOS/Linux
venv\Scripts\activate     # Windows
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

# Frontend setup
cd ../frontend
npm install
npm run start
```
